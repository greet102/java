【最重要的一句话】这台电脑每次开机都会重置：node_modules 和
target 文件夹会被删除，其他内容（源码、脚本、数据库、本文件）保留。
启动脚本 v2 已内置全部自动恢复逻辑，不要重复排查已确认的事实，
按本手册直接执行即可。

三、启动脚本 v2 行为（2026-10-14 重写，已实测通过）
----------------------------------------------------------------
核心原则：绝不依赖 target 和 node_modules 的旧内容，
每次启动都从源码完整重建。

一键启动.bat（总入口）：
1. 后端（springBootTest\启动后端.bat）：
   a. 自检 MySQL 3306，未运行给警告
   b. 8081 已监听则直接跳过（防重复启动）
   c. 自动定位 Java/Maven，设置 JAVA_HOME，清除 SERVER__PORT/HOST
   d. 无条件 mvn package -DskipTests（全程显示输出，10秒-3分钟）
   e. 数据库自检：blog_db 缺失则自动导入 sql\blog.sql
   f. start 新窗口运行 jar，等待 8081 就绪（最长180秒）
2. 前端（blog-vue\启动前端.bat）：
   a. 5173 已监听则直接跳过
   b. 自动定位 npm（PATH → D:\Program Files\nodejs → workbuddy node）
   c. 无条件 npm install（npmmirror 镜像，--no-audit --no-fund）
      并校验 node_modules\.bin\vite.cmd 存在
   d. start 新窗口运行 npm run dev，等待 5173 就绪（最长120秒）
3. 汇总检查两个端口，显示 启动成功/未完成，结果追加 启动日志.txt

双击入口：java-main\一键启动.bat → 浏览器 http://localhost:5173
→ 喵站长 / 123456 登录。全程约 1-5 分钟，窗口持续滚动输出属正常。

排查启动失败时按顺序看：
  java-main\启动日志.txt（哪一步失败）
  → springBootTest\run.log（后端报错详情）
  → blog-vue\npm.log（前端报错详情）

停止：双击 一键停止.bat，或直接关掉两个服务窗口。

四、AI 在终端里操作时的坑（本机特有，已踩过，勿再踩）
----------------------------------------------------------------
1. shell 设有 HTTP_PROXY=127.0.0.1:63252：
   curl 访问 localhost 必须加 --noproxy '*'，否则返回 502
2. shell 设有 SERVER__PORT=63237，会覆盖 Spring Boot 端口：
   启动 Java 服务前先 env -u SERVER__PORT -u SERVER__HOST
3. Git Bash 里 taskkill 参数用单斜杠：taskkill /PID xxx /F
4. Git Bash 的 curl -c/-b cookie jar 对 localhost 的 JSESSIONID
   保存不上：测试会话接口时用 -H "Cookie: JSESSIONID=xxx" 手动带
5. 生成 bat 必须同时满足两个条件（缺一不可，否则 cmd 静默失败不执行）：
   a) GBK 编码：iconv -f UTF-8 -t GBK 输入.tmp > 输出.bat
   b) CRLF 换行：cmd 不接受 LF 换行的批处理，必须再加工：
      iconv -f UTF-8 -t GBK 输入.tmp | sed 's/$/\r/' > 输出.bat
      （已生成的 LF 旧文件修复：sed 's/$/\r/' 旧文件 > 新文件）
6. 从 Git Bash 直接 cmd //c 调用中文名 bat 会失败（参数不转换），
   用 PowerShell 工具 + 调用运算符：& 'C:\...\一键启动.bat' auto
   （输出捕获不到 GBK 中文属正常现象，以副作用/端口状态为准）
7. ( )& 方式脱离的进程会随会话被杀，验证用的长跑服务统一用
   后台任务方式启动，结束时按端口 PID taskkill
8. 脚本里的 start "标题" cmd /k 开新窗口只在真实桌面双击时有效；
   沙箱无桌面环境无法弹窗，验证服务要直接用 java -jar / npm run dev
9. PowerShell 工具里不能调 cmd.exe（安全策略拦截），跑 bat 用调用
   运算符 & '路径\脚本.bat'；PowerShell 工具的 stdout 经常捕获不到，
   需要输出时让命令重定向到文件再读
